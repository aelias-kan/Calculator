# Calculator
Hey, I'm Ilyas, and this is my calculator project, the final project of The Odin Project's Foundations course.

The goal is to build a working calculator using HTML, CSS, and JavaScript while putting everything I've learned so far into practice.

Features

Basic arithmetic: addition, subtraction, multiplication, and division.

Clear and delete functions.

Decimal number support.

Chained calculations.

Keyboard support.

Error handling for invalid operations.

Built With

HTML

CSS

JavaScript

What I Learned

This project helped me practice DOM manipulation, event handling, JavaScript functions, and problem-solving while building something interactive from scratch.

Future Plans

I want to expand this project into a scientific calculator by adding:

Square roots and powers.

Trigonometric functions (sin, cos, tan).

Logarithms and factorials.

Constants like π and e.

Parentheses and more complex expressions.

Final Thoughts

This project marks the end of my Foundations journey. There's still a lot to learn, but I want to keep improving the calculator and use it as an opportunity to grow as a developer.
